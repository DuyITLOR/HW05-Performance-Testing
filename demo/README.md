# demo/ — bãi thử khi quay video

Nội dung folder này **bị .gitignore** (trừ chính file README này) và **không thuộc bài nộp**.

Dùng để chạy nháp lúc tập quay video: lượt JMeter ngắn, ảnh chụp thử, file `.jtl` bỏ đi. Mục
đích là không để bằng chứng nháp lẫn vào `results/` — thứ sẽ đi vào bản nộp và bị §11 kiểm tay.

Lượt chạy **chính thức** luôn đi qua `tools/run-scenario.sh` và ghi vào `results/`, kèm một dòng
trong `results/run-log.md`.

Kịch bản quay: [`docs/kich-ban-video-demo.md`](../docs/kich-ban-video-demo.md).
